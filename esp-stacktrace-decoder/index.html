ESPHome Device Builder stack trace decoder

This page decodes ESP crash backtraces for the ESPHome Device Builder dashboard. The dashboard embeds it in a hidden frame and hands it a firmware ELF and a crash dump; it answers with the decoded frames.

Your firmware is never uploaded. It is decoded in this browser tab, by WebAssembly, and this page is served with a Content-Security-Policy that permits no network requests other than loading its own code. There is nothing here to use on its own; open the standalone decoder if you want to decode a trace by hand.
